매뉴얼 근거와 구현 범위

첨부한 교육장 배선도 슬라이드 5의 지하서울 원본 이미지를 수정 없이 사용합니다. 모드 버튼과 경로 확인선, 클릭 영역만 덧씌웠습니다.

4A-B072T배선도 5 / 실무5 본문 p.362

바로잡은 내용

3A는 2T 쪽 상행 출발신호기입니다. 이전 버전의 상단 배치, 임의 B071T, 가상 W1·W2·E2 궤도와 임의 1A-2T·2A-1T 진로를 제거했습니다. 서쪽 21A/B·22A/B와 동쪽 51A/B·52, MT 유치선은 원본 그대로 표시합니다.

조작 방법

CCM → 3A 신호기 → RT_3A_B065T를 선택하면 녹색 진로와 진행 표시가 나타납니다. 설정된 3A를 다시 누르고 예를 선택하면 신호 정지·진로 해정이 이루어집니다. MMI 진로제어에서도 설정·해정을 할 수 있습니다. 전환기는 LS 클릭으로 반대 위치 조작, MMI에서 정·반위 선택 조작을 연습합니다.

연습 모델의 범위

매뉴얼 p.5–8의 기본 진로 설정·정지·해정 절차와 제공 사진의 3A-B065T 표시를 반영했습니다. 현재는 접근 열차가 없는 상황입니다. 열차 이동, 궤도 점유, 접근쇄정 시간, 연속제어, 세부 연동표 조건은 재현하지 않습니다. 동일 신호기·공유 경로와 서쪽 건넘선 중복 설정을 막고, 설정 진로가 있는 쪽의 수동 전환기 조작을 막는 연습용 보호조건을 적용했습니다. 이는 실제 연동장치의 전체 조건표를 대신하지 않습니다.

전환기 초기 정위는 연습용 초기값입니다. 정·반위 조작 상태를 표시하지만 실제 배선 형상과 자동 전환 조건은 재현하지 않습니다. 3A-B065T 외 진로의 진행 표시는 기본 연습용으로, 현시 종류·등색 조합 전체를 검증한 것이 아닙니다.

전체 역 범위

이번 수정은 관제 대상 15개 역의 기본 제어와 전체 구간 다이아·스케줄 연습을 제공합니다. 청량리~수원 관제 대상 연동역 15개를 전환해 기본 진로를 조작합니다. 다이아에는 중간 정차역을 포함해 33개 역을 표시합니다. 전체 연동표 및 모든 입환진로는 미검증입니다.
