# CTC LAB v0.13.0 — 데스크톱 관제 조작 실습

PC의 넓은 화면과 마우스를 사용하는 실습입니다. 모바일 화면과 모바일 검증은 제공하지 않습니다.

## 실행

`index.html`을 브라우저로 열거나, 저장소 루트에서 `python3 -m http.server 8765 --directory simulator`를 실행하고 http://localhost:8765/ 에 접속합니다. 이 개발 환경에서는 file:// 검사가 관리자 정책에 막혀 HTTP 실행을 검증했습니다.

## 첫 연습

1. 지하서울 선택 → CCM → 예.
2. 3A 신호기 → RT_3A_B065T. 녹색 진로와 진행 신호를 확인합니다.
3. 3A 재선택 → 예: 정지·해정. 아니오를 누르면 유지합니다.
4. MMI 진로제어에서도 같은 상태를 조작할 수 있습니다. 교재의 3A-B070T는 MMI 목록에 있습니다.

## 우클릭·열번창

LS 빈 공간 우클릭 → 현재역/전체역 베이스스캔·인쇄·재실행·표지판·Overview. 빈 흰 창 우클릭 또는 더블클릭 → 열차번호 입력. 번호가 있는 창은 추가·수정·삭제·이동·교환·속성 조회를 제공합니다. 이동·교환은 원본 번호 선택 → 목적지 창 클릭 → 확인 순서이며 Esc로 취소합니다. 다른 역으로도 이동할 수 있습니다.

원본 PPTX 열번창 276개 중 71개는 선로 위에 겹친 흰 블록입니다. 이 창들도 입력·표시·우클릭 대상으로 사용합니다. 중간역 이름판은 위로 올리고 선로별 창 높이를 맞췄습니다. 표지판은 끌어서 이동하고 우클릭으로 고정·수정·삭제합니다.

수동 열차번호와 표지판은 기록 저장에 포함됩니다. 모의 점유·다이아 계산과는 별도 상태이며 실제 궤도 검지에 따른 자동 열번 추적 모델은 아닙니다. 스캔·재실행 시 설정과 표시를 유지하며, 브라우저 새로고침 시 실행 중 상태는 초기화됩니다.

## 화면과 기능

상단 메뉴와 전체 가로 폭을 사용하고, 세로 선로 간격·글자·신호기를 키웠습니다. 15개 취급역의 구내·관할 중간역을 넓은 간격의 SVG로 표시합니다. 금천구청은 석수까지, 안양은 관악·명학을 포함합니다. 캡처 배경·긴 신호기 지시선·LS 전환기 조작 버튼은 사용하지 않습니다. 전환기 조작은 MMI에서 합니다.

246개 신호기·118개 전환기 그룹과 654개 도출 경로를 제공합니다. 설정·정지·해정, 경합 거부, 모의 점유·통과·연속제어, 쇄정, 접근쇄정(접근 열차를 넣고 정지할 때 장내 90초·출발 30초)을 연습합니다. N/R 상태에 따라 실제 SVG 연결 형태도 바뀝니다.

확인된 5개 역의 LS 메뉴 95개와 용산 10개 신호기의 확인 답변 26개를 적용했습니다. 미확정 신호기는 배선 연결에서 도출한 연습 경로임을 표시합니다. 세부 연동표·측방방호·궤도별 순차 해정과 전체 실설비 조건을 검증한 모델은 아닙니다.

MMI 열차 그래프에서 교육용 다이아를 열고, 열차스케줄 관리에서 전체 33개 역의 계획을 생성·수정·복사·운휴할 수 있습니다. 10개 실습 과제를 제공합니다.

검증 명령과 결과는 `검증결과.md`를 확인하세요. 실행본에는 원본 대조용 자산도 보관하지만 LS 화면은 이미지 요청 없이 동작합니다.
