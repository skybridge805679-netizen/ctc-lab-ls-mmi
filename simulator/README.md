# CTC LAB v0.21.0 — 데스크톱 관제 조작 실습

M1 Mac·Windows용 데스크톱 앱은 저장소 루트의 Electron 구성을 사용합니다. [설치·빌드·검증 범위](../docs/v0.21.0-데스크톱앱.md)

**↗ MMI 새 창**으로 LS·MMI를 두 브라우저 창에서 조작합니다. 붉은 알람은 MMI, LS 제어 확인은 LS에 표시합니다. MMI 창을 닫으면 같은 상태로 합쳐집니다. 원본 LS 창은 계속 열어 두세요. [사용법·구조·범위](../docs/v0.20.0-LS-MMI분리.md)

원본 회로 317개를 구내망과 연결하고, 안양의 두 합성 진로를 원본 연결로 복원했습니다. [대조·검증·자료 범위](../docs/v0.19.4-회로단위연결.md)

Claude 선로망을 통합하고, 앞 역의 실제 통과·지연·폐색을 뒤 역 운행에 연결했습니다. [전체 구조·검수·한계](../docs/v0.19.3-전체선로망검수.md)

전 역 19,392쌍의 경합을 대조해 독립 선로의 공통 정위 쇄정을 허용했습니다. 기존 안양 확인 조합 외 1,541쌍의 과잉 차단을 수정했습니다. [근거·검증·한계](../docs/v0.19.2-진로경합전수대조.md)

대피·비상 시나리오의 이동이 진로 점유·도착·통과로 이어집니다. 시나리오 창의 이동 상태를 확인하고 가상시계로 진행하세요. [사용법·검증·범위](../docs/v0.19.0-시나리오운행연계.md)

열차번호·접근·진로 이동에 따른 붉은 점유 표시를 통합하고 배속·Overview 연동을 보완했습니다. [통합 범위·검증·한계](../docs/v0.18.3-Claude통합.md)

괄호의 폭·선로 여백을 통일하고 기지 문구의 중심·상하 간격과 민트 안내 패널을 정돈했습니다. [정렬 화면](../docs/v0.18.2-위치정렬.md)

PC의 넓은 화면과 마우스를 사용하는 실습입니다. 모바일 화면과 모바일 검증은 제공하지 않습니다.

## 오르페이아 전체 디자인

이미지 생성 에셋 3종을 포함한 #BEE3E3 테마입니다. 헤더·브랜드·MMI 대기 배경·사용 안내와 모든 창·표·폼을 통일했습니다. 이미지와 아이콘은 로컬 실행본에 포함되며 LS 판독 영역의 의미 색은 유지합니다. [디자인과 에셋](../docs/v0.18.0-오르페이아디자인.md)

## LS 표시 수정

CCM 클릭 시 사진의 제어확인과 Y/N 조작을 제공합니다. 역명판은 지하청량리~지하서울 파랑·나머지 검정이며 설비 기본색과 장애색을 구별합니다. 진로 메뉴는 커서가 올라간 한 항목만 채우고 키보드 포커스는 윤곽선으로 표시합니다. [화면·검증](../docs/v0.17.1-LS표시수정.md)

## 추가 기능

자동제어(기본 OFF)와 가상 열차·열번 이동, 대피 5종·비상시조치 9종·스케줄 연습 2종, 로그재생·조회·노트·스케줄ID·진입예고·선호 역·설비 장애·CDRS·운전정리 대장을 제공합니다. 새 기능도 #BEE3E3 오르페이아 테마를 사용합니다. [메뉴별 사용법·검증·현재 한계](../docs/v0.17.0-통합.md)

시나리오 진행에 따라 LS 열번창에 등장 열차가 배치·이동합니다. 알람은 체크한 항목만 확인 처리하며, 표지판은 반투명·크기 조절을 지원합니다. 진로는 신호기 옆 목록에서 선택하고 해정 확인은 Y/N으로 답할 수 있습니다. 필기 퀴즈는 제거했고 교재 레퍼런스는 유지합니다.

## 오르페이아 UI

`#BEE3E3` 기반의 민트·청록색 테마입니다. 관제 프로그램의 메뉴 계층과 선로·신호 상태의 의미를 보존합니다. [디자인·팔레트·화면](../docs/오르페이아디자인.md)

## 실행

`index.html`을 브라우저로 열거나, 저장소 루트에서 `python3 -m http.server 8765 --directory simulator`를 실행하고 http://localhost:8765/ 에 접속합니다. 이 개발 환경에서는 file:// 검사가 관리자 정책에 막혀 HTTP 실행을 검증했습니다.

## MMI 통합

MMI↓로 메뉴·창 작업 영역에 이동합니다. 현장설비제어는 LS와 같은 상태를, 열차번호제어는 같은 열번창 데이터를 사용합니다. 열차스케줄 메뉴에서 온라인 그래프와 스케줄을 열고 제목줄의 도킹/창으로로 배치합니다. 그래프·스케줄의 지연·운휴·속성 변경은 서로 반영됩니다. 편집 초안은 이미 열린 창을 메뉴에서 다시 선택해도 유지되며 외부 변경이 생기면 재조회 안내를 합니다. 기록 저장은 시각표와 MMI 로그도 포함합니다.

[사용법·구조·현재 한계](../docs/MMI와그래프통합.md)

## 첫 연습

1. 지하서울 선택 → CCM → 예.
2. 3A 신호기 → RT_3A_B065T. 녹색 진로와 진행 신호를 확인합니다.
3. 3A 재선택 → 예: 정지·해정. 아니오를 누르면 유지합니다.
4. MMI 진로제어에서도 같은 상태를 조작할 수 있습니다. 교재의 3A-B070T는 MMI 목록에 있습니다.

## 우클릭·열번창

LS 빈 공간 우클릭 → 현재역/전체역 베이스스캔·인쇄·재실행·표지판·Overview. 빈 흰 창 우클릭 또는 더블클릭 → 열차번호 입력. 번호가 있는 창은 추가·수정·삭제·이동·교환·속성 조회를 제공합니다. 이동·교환은 원본 번호 선택 → 목적지 창 클릭 → 확인 순서이며 Esc로 취소합니다. 다른 역으로도 이동할 수 있습니다.

원본 PPTX 열번창 276개 중 71개는 선로 위에 겹친 흰 블록입니다. 이 창들도 입력·표시·우클릭 대상으로 사용합니다. 중간역 이름판은 위로 올리고 선로별 창 높이를 맞췄습니다. 표지판은 끌어서 이동하고 우클릭으로 고정·수정·삭제합니다.

수동 열차번호와 표지판은 기록 저장에 포함됩니다. 자동제어를 켜면 시각표 기반 가상 열차가 열번창과 경로 단위 점유를 갱신합니다. 실제 궤도 검지에 따른 자동 열번 추적 모델은 아닙니다. 스캔·재실행 시 설정과 표시를 유지하며, 브라우저 새로고침 시 실행 중 상태는 초기화됩니다.

## 화면과 기능

상단 메뉴와 전체 가로 폭을 사용하고, 세로 선로 간격·글자·신호기를 키웠습니다. 15개 취급역의 구내·관할 중간역을 넓은 간격의 SVG로 표시합니다. 금천구청은 석수까지, 안양은 관악·명학을 포함합니다. 캡처 배경·긴 신호기 지시선·LS 전환기 조작 버튼은 사용하지 않습니다. 전환기 조작은 MMI에서 합니다.

246개 신호기·118개 전환기 그룹과 656개 경로를 제공합니다. 설정·정지·해정, 경합 거부, 모의 점유·통과·연속제어, 쇄정, 접근쇄정(접근 열차를 넣고 정지할 때 장내 90초·출발 30초)을 연습합니다. N/R 상태에 따라 실제 SVG 연결 형태도 바뀝니다.

확인된 5개 역의 LS 메뉴 95개와 용산 10개 신호기의 확인 답변 26개를 적용했습니다. 미확정 신호기는 배선 연결에서 도출한 연습 경로임을 표시합니다. 세부 연동표·측방방호·궤도별 순차 해정과 전체 실설비 조건을 검증한 모델은 아닙니다.

MMI 열차 그래프에서 교육용 다이아를 열고, 열차스케줄 관리에서 전체 33개 역의 계획을 생성·수정·복사·운휴할 수 있습니다. 10개 실습 과제를 제공합니다.

검증 명령과 결과는 `검증결과.md`를 확인하세요. 실행본에는 원본 대조용 자산도 보관하지만 LS 화면은 이미지 요청 없이 동작합니다.
