## 다이아·온라인 스케줄
MMI 열차 그래프 → 온라인 열차그래프 열기에서 시간/역 축, 열차 검색, 지연·운휴를 조작합니다. 열차스케줄 → 온라인 열차스케줄 관리에서 생성·수정·복사·전체 운휴를 편집 적용하면 같은 다이아 데이터가 바뀝니다. LS/MMI 제어역은 15개, 스케줄 경유역은 전체 33개입니다. 시각표는 교육용이며 실제 신호·점유와 연동되지 않습니다.

## 구현
- 원본 배선도 기반 15개 제어역 전환과 총 39개 기본 진로(세부 연동 미검증)
- LS 진로목록, 설정, 정지·해정, 취소 시 유지
- MMI 진로 설정·해정, LS와 상태 공유
- 제어모드 및 LOCAL 인계 수락/거절
- 전환기 정·반위 조작 상태, 현재역/전체역 베이스스캔
- 9개 연습 과제, 기록 저장, 초기화

## 고증 및 구현 범위
매뉴얼 인쇄 p.5–8의 기본 진로 조작, p.11–13의 전환기 조작, p.14–17의 모드 조작을 참고했습니다. 3A 목록은 p.6, 배선은 PPTX 슬라이드 5, 3A-B065T 녹색 경로는 제공 CAI 사진에 근거합니다.
접근 열차가 없는 기본 연습 모델입니다. 열차 이동·궤도 점유·접근쇄정 타이머·연속제어·전체 연동표은 미구현입니다. 전환기 초기 정위는 연습용 값이며 실제 정·반위 선형 변화와 자동 전환 조건은 재현하지 않습니다. 충돌 방지는 제한된 연습용 보호조건입니다. 전체 시험설비 복제본이 아닙니다.
