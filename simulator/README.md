## 실행
압축을 푼 뒤 index.html을 브라우저로 여세요. 설치나 계정이 필요 없습니다.
로컬 서버 실행: 저장소 루트에서 `python3 -m http.server 8765 --directory simulator`

## 첫 연습
1. 취급역에서 지하서울을 선택하고, 해당 역 CCM → 예.
2. 하단 선로의 3A 신호기 → RT_3A_B065T.
3. B065T–X1T–21BT의 녹색 진로와 3A 진행 표시를 확인.
4. 3A를 다시 클릭 → 예. 신호 정지와 진로 해정 확인.
5. MMI의 진로제어 → 3A → 3A-B065T → 설정/해정 → 확인으로 같은 연습 가능.
작게 보이면 배선 확대를 누르세요.

## 다이아·온라인 스케줄
MMI 열차 그래프 → 온라인 열차그래프 열기에서 시간/역 축, 열차 검색, 지연·운휴를 조작합니다. 열차스케줄 → 온라인 열차스케줄 관리에서 생성·수정·복사·전체 운휴를 편집 적용하면 같은 다이아 데이터가 바뀝니다. LS/MMI 제어역은 15개, 스케줄 경유역은 전체 33개입니다. 시각표는 교육용이며 실제 신호·점유와 연동되지 않습니다.

## 고증 및 구현 범위
매뉴얼 인쇄 p.5–8의 기본 진로 조작, p.11–13의 전환기 조작, p.14–17의 모드 조작을 참고했습니다. 3A 목록은 p.6, 배선은 PPTX 슬라이드 5, 3A-B065T 녹색 경로는 제공 CAI 사진에 근거합니다.
경로 단위 모의 점유·통과·연속제어·일괄정지·전환기 쇄정을 지원합니다. 실제 열차 추적, 궤도별 순차 해정, 접근쇄정 시간과 전체 연동표는 미구현입니다. 전환기 N/R은 직진·분기 연결에 따른 연습 표시이며 실설비 조건표로 확정하지 않았습니다.

## 설정·취소·해정 연습
과제 09를 시작한 뒤 CCM → 3A → RT_3A_B065T → 3A → 아니오 → 3A → 예 순서로 조작합니다. 취소 후에는 진로가 유지되어야 하며, 마지막 정지·해정까지 마친 뒤 완료 상태를 확인합니다. 과제 05도 B070T 설정 → 해정 → B065T 설정 순서를 검사합니다.

## 배선 배경 교체
1.전체노선.pdf의 원본 JPEG 4장을 사용합니다. 전체노선 보기에서 4쪽을 전환하고 1쪽의 역 이름을 누르면 선택역 제어 화면으로 돌아옵니다. 배경 이미지는 재압축하지 않았고 조작 영역만 별도로 표시합니다.

전체 구간은 각 PDF 시트를 자르지 않고 이어 표시합니다. 역 선택은 제어역 변경과 스크롤 이동입니다. `＋ / − / 전체 폭 맞춤`으로 배선을 확인하세요. 경로 아래의 모의 열차 진입·통과로 점유/쇄정을 연습하고, MMI에서 연속진로제어·일괄정지·전환기 쇄정/해제를 선택할 수 있습니다. 실설비 전체 연동표 재현은 아닙니다.
