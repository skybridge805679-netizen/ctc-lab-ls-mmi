## 첫 연습
1. LS 상단 CCM → 예.
2. 하단 선로의 3A 신호기 → RT_3A_B065T.
3. B065T–X1T–21BT의 녹색 진로와 3A 진행 표시를 확인.
4. 3A를 다시 클릭 → 예. 신호 정지와 진로 해정 확인.

작게 보이면 배선 확대를 누르세요.

## 구현
- 원본 지하서울 배선도와 근거가 있는 5개 진로
- LS 진로목록, 설정, 정지·해정, 취소 시 유지
- MMI 진로 설정·해정, LS와 상태 공유
- 제어모드 및 LOCAL 인계 수락/거절
- 전환기 정·반위 조작 상태, 현재역/전체역 베이스스캔
- 9개 연습 과제, 기록 저장, 초기화

## 고증 및 구현 범위
매뉴얼 인쇄 p.5–8의 기본 진로 조작, p.11–13의 전환기 조작, p.14–17의 모드 조작을 참고했습니다. 3A 목록은 p.6, 배선은 PPTX 슬라이드 5, 3A-B065T 녹색 경로는 제공 CAI 사진에 근거합니다.
접근 열차가 없는 기본 연습 모델입니다. 열차 이동·궤도 점유·접근쇄정 타이머·연속제어·전체 연동표·다른 역은 미구현입니다. 전환기 초기 정위는 연습용 값이며 실제 정·반위 선형 변화와 자동 전환 조건은 재현하지 않습니다. 충돌 방지는 제한된 연습용 보호조건입니다. 전체 시험설비 복제본이 아닙니다.

## 설정·취소·해정 연습
과제 09를 시작한 뒤 CCM → 3A → RT_3A_B065T → 3A → 아니오 → 3A → 예 순서로 조작합니다. 취소 후에는 진로가 유지되어야 하며, 마지막 정지·해정까지 마친 뒤 완료 상태를 확인합니다. 과제 05도 B070T 설정 → 해정 → B065T 설정 순서를 검사합니다.
