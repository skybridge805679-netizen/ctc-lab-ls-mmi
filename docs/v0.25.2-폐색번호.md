# v0.25.2 — 폐색 번호와 의왕~수원 프리셋

전체노선 PDF의 작은 검은 표식에는 숫자가 없었다. 사용자 제공 PPT `배선도(관제교육장).pptx`의 슬라이드 2~19를 대조하여 폐색 번호 274개를 복원했다. 원본에서 확인한 숫자만 표시하고 회로 번호나 화면 순서로 번호를 자동 부여하지 않는다. 추가 역간 슬라이드 13·16·18도 포함한다.

검은 몸체 안에 흰 숫자를 넣고 방향 기호를 복원했다. 인접 선로의 번호끼리 겹치지 않도록 선로 위·아래 간격을 조정했다. 흰 열번창과 폐색 표식은 별개이며, 폐색 표식이 열번창·전환기·신호기의 클릭을 가리지 않는다. 기존 구내 조작과 좌우 창 끝까지의 수평 본선 연장은 유지했다.

## 의왕 구내와 성균관대·화서 분리

하단 탭·LS 선택 목록·좌우 전환 순서는 **의왕 → 의왕~수원 → 수원**이다. 의왕~수원에 성균관대·화서, 4개 본선의 모든 회로 코드·폐색 번호·열번창·승강장 표시를 옮겼다. 의왕 화면은 구내 배선을 가로로 확대하여 조작 공간을 확보했다. 프로그램 메뉴의 **실습 화면 → LS 추가 창 → 의왕~수원**으로 별도 LS 창에서도 열 수 있다. 운영자 선호화면과 Overview에도 추가했다.

취급역은 기존 15개이고 LS 화면만 16개다. 새 프리셋은 **역간 운행 감시 전용**이다. 제어할 구내 설비가 없으므로 AUTO·CCM·LOCAL·일괄정지·장치 상태 박스를 표시하지 않는다. LS에서 열번 입력·수정·이동·표지판 편집·현재역 초기화도 제공하지 않는다. 열번과 점유는 의왕과 같은 엔진 상태에서 받아 표시하며, 열차 속성 조회·화면 인쇄·Overview만 가능하다. 새 취급역이나 복제 운행 상태를 만들지 않는다. 의왕에서 설정한 구내 진로·전환기는 의왕 화면에 표시하고, 역간 프리셋은 해당 구간의 실제 점유와 열번을 표시한다. 두 화면을 오가도 열차번호를 유지한다.

기존 의왕 그림의 회로·폐색 번호·열번창을 두 화면의 합계와 대조하여 누락·중복 없이 나누었다. 구내 신호기와 전환기 조작은 의왕 화면에 유지한다. `SimLS.render`의 프리셋 없는 호출은 원본 전체 구간을 대조하는 용도로 유지하며, 일반 화면과 Overview는 선택한 프리셋으로 그린다.

## 데이터와 검증

[폐색 전사](../references/transcriptions/block-signals.json)에 원본 PPT 해시·슬라이드·기호 좌표·인접 회로 좌표·OCR 후보와 확인한 번호를 보관한다. `code`는 PPT의 인접 회로 표기이며, `anchorCode`는 현재 PDF 배치의 앵커다. 판본 차이가 있는 금정 우측 끝·수원은 앵커를 명시했다. 전사는 폐색 번호 표시의 근거이며 실설비의 신호 현시·연동 조건을 추가한 진로표는 아니다. 원본 첨부 PDF·PPT는 변경하지 않았다.

- 단위 시험 74개: 원본 해시·274개 번호 대조, 15역 전체 번호 표시, 의왕 두 프리셋의 회로·번호·열번창 누락/중복 방지, 구내 확대와 엔진 상태 불변을 확인했다.
- 1440·1920 폭의 16개 LS 화면에서 정위·반위 상태의 글자 겹침과 잘림을 검사했다.
- 실제 브라우저에서 의왕 → 의왕~수원 → 수원 이동, 감시 화면의 제어·편집 차단, 외부 엔진 열번·점유 갱신·재전환 후 유지, 선호화면 재적용, 새 프리셋 크기 변경을 확인했다.
- 모든 취급역의 전환기 클릭·시나리오 자동 진행·시간표 저장/열기/실행 취소 및 데스크톱 6개 창 크기를 검사했다. 모바일은 검사하지 않는다.
- 실제 Linux Electron에서 별도 엔진·세션 복구·여러 LS와 새 의왕~수원 창의 공통 엔진 연결을 검사했다. Linux·Windows x64·Mac ARM64 앱 패키지의 전체 런타임 파일을 소스와 대조하고 Linux 패키지도 실행했다. Windows·Mac 네이티브 실행과 최종 설치 파일 생성은 GitHub Actions에서 수행한다.
