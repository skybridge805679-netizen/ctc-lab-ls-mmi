# v0.22.0 — 프로그램 창 구성과 엔진 세션 통합

Claude 브랜치 `claude/practical-dirac-68tgp6`의 실제 원격 커밋 `1ab67779bbb01b8cb1e9ed1cce5eaabaa3b8268a`을 병합했다. 그 이력의 `b8f59d3` Windows ASAR 경로 수정, `bf63c41` 프로그램형 창 구성, `1ab6777` 폴더 분리를 포함한다. Windows 오류 검사 보완과 이번 창 수명·엔진 세션 작업을 함께 적용한다. 버전을 0.22.0으로 올려 새 설치본 릴리스 대상에 포함한다.

## 프로그램 화면과 디자인

LS는 상단의 얇은 오르페이아 도구 모음·화면 전체의 배선도·하단 15개 취급역 바로가기를 사용한다. 진로·쇄정 현황과 연습 기록은 우측 패널에서 연다. MMI는 빈 작업 화면으로 시작하고 메뉴에서 현장제어·스케줄 등을 연다. 온라인 열차 그래프는 LS·MMI와 별도의 OS 창으로 열린다. 세 화면의 상태와 시계는 하나다. 그래프 축·보기·색상 같은 설정창도 그래프 안에서 열려 MMI 종료에 영향을 받지 않는다.

주조색 #BEE3E3, 짙은 청록 도구 모음, 밝은 민트·종이색 창과 기존 로컬 오르페이아 에셋을 유지한다. LS의 녹색·노란색·붉은색은 설비 의미를 보존한다. 별도의 장식 이미지나 외부 이미지 서비스 의존성을 추가하지 않았다.

## MMI 닫기: LS와 합치지 않음

MMI를 닫으면 LS에 MMI 화면이나 알람이 나타나지 않는다. 프로그램 안의 보이지 않는 문서에 살아 있는 화면 요소를 보관하고, ‘MMI 창’ 또는 Cmd/Ctrl+2로 다시 열 때 입력·편집·미확인 알람·열린 확인창을 복원한다. MMI가 닫혀 있어도 시계와 독립 열차 그래프는 계속 동작한다. 자동 합치기 및 ‘한 화면으로’ 조작은 제거했다. LS 원본 창을 닫거나 앱을 종료하면 세션 전체가 종료되는 점은 유지한다.

‘도킹’은 사용자의 선택에 따라 **창 고정 / 자유 배치**로 이름을 바꾸고 유지한다. MMI 내부 창을 작업 영역에 고정해 정렬하거나, 제목 막대를 끌어 옮기는 창으로 바꾸는 기능이다. LS·MMI를 합치는 기능과는 별개다.

## 엔진 세션과 성능

`engine/session.js`가 15개 취급역의 상태·선택 역·명령 전달·전체 시계 진행·스냅샷을 소유한다. `ui/app.js`는 세션의 상태를 참조하고 화면과 사용자 입력을 연결한다. 역별 Core 인스턴스를 재사용해 매 시계 갱신과 설비 조회에서 같은 구성을 반복 생성하지 않는다.

DOM 없는 Node 실행에서 15역 시계, 안양의 두 독립 진로 동시 설정, 역 전환, 세션 간 상태 격리와 스냅샷 복사를 검사한다. 이는 세션을 화면 없이 실행할 수 있는 기반이다. 자동제어·시나리오 UI 연결, 렌더링·연습·내보내기는 아직 UI 어댑터가 연결하며, 엔진을 Electron 별도 프로세스로 옮겨 LS 종료와 무관하게 실행하는 단계까지 완료한 것은 아니다. 실습 세션 자동 저장·복구나 자동 업데이트를 새로 구현했다고 간주하지 않는다.

## Windows 패키지 검사 보완

ASAR 라이브러리는 호스트 운영체제의 경로 구분자로 디렉터리를 탐색한다. Windows에 POSIX 경로 `simulator/assets/orpheia/emblem.png`를 전달하면 파일이 존재해도 찾지 못한다. 실제 ASAR 라이브러리의 Windows 경로 처리로 원래 오류를 재현하고, 네이티브 구분자로 수정한 경로가 성공함을 회귀 검사한다.

새 감사는 진입 HTML이 참조하는 UI·엔진·CSS와 전체 런타임 에셋, 총 88개 필수 파일을 원본 파일과 바이트 단위로 대조한다. 실제 누락·변조는 계속 실패한다. 목록의 경로도 정규화해 레퍼런스 원본·개발용 Playwright·e2e/테스트 파일이 설치본에 섞이지 않는지 검사한다. 폴더 이동에 맞춰 엔진 경로·테스트 제외 규칙도 갱신했다.

## 검증과 범위

Node 42개 시험과 실제 Electron 소스/ASAR 실행본을 검사한다. 데스크톱 1440·1920px 브라우저 시험 및 작은 CI 작업 영역 1024×768의 네이티브 창 보정을 확인한다. MMI 닫기 후 LS 무합침·미확인 알람/모달 재열기·시계/독립 그래프 유지·창 고정/자유 배치·시나리오와 전체 선로망을 검증한다. 모바일 시험은 하지 않는다.

macOS ARM64·Windows x64 설치본은 각 운영체제 Actions 시험과 빌드가 모두 성공해야 Releases에 게시된다. 이 클라우드의 GitHub Actions API 조회는 제한돼 있어 두 운영체제의 최종 성공을 직접 확인했다는 뜻은 아니다. 공인 서명·Apple 공증은 여전히 미포함이다.
