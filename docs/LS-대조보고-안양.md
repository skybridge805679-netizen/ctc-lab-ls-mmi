## 고치지 못한 것

- 장내·출발 신호기 옆의 흰 「T」 상자(1A·1B·3B·3C·4B·4C·2A·2B): 어느 신호기에 붙는지 정하는 데이터가 없다. 모든 슬라이드에서 뽑아 데이터로 만든 뒤 그려야 한다.

## 다른 역에 함께 적용된 것

- 장내·출발 신호기의 긴 몸체와, 원본 폭 열번칸(94)이 원본 좌표 화면 전체에 적용된다. 겹침 검사는 0건이다.
- 역간 감시 화면으로 가는 화살표가 역 이름을 쓴다(금정 ← 「안양」, 군포 → 「의왕」, 의왕 ← 「군포」, 의왕 → 「수원」). 원본 슬라이드 14~17과 같다.
