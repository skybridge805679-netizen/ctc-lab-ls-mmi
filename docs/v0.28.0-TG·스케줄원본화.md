# v0.28.0 — T/G·열차스케줄 화면을 원본 사진대로 (2026-10-30)

근거: 사용자가 실물 MMI·T/G를 찍은 사진 13장과 설명(2026-10-30). 사진 원본은 저장소에 넣지 않았습니다.
사진의 운영자 ID는 옮기지 않았고(`MMI-1`로 표시), 패턴 등록자 `MIG_USR`(이관 계정)와 등록일시는 화면에 나온 그대로 둡니다.

## 사용자 설명 (그대로 반영)
- 열차선을 마우스로 끌어 고치는 기능은 없다. **툴팁보기**로 열차선을 클릭해 선택한 뒤 **F5** → 열차 스케줄 수정, **Ctrl+C** → 열차 복사.
- 경합을 따로 표시하는 기능은 없다. 관제사가 **십자선보기**로 어디서 언제 겹치는지 읽고 경합해소를 한다.
- 왼쪽 세로 아이콘(위→아래): 열기, 복사, 붙여넣기, 열차생성, 열차수정, 인쇄, 이전화면, 다음화면, 열차속성, 열차보기옵션, 열차검색, 확대영역설정, 툴팁보기, 십자선보기, 영역확대, 돋보기, 즐겨찾기 설정, 즐겨찾기 가기.
- 경유역 정보표는 고칠 수 있다.

## 패턴 데이터
- 사진으로 모든 행을 확인한 패턴 2개를 그대로 넣었습니다: `추석`(상행 KTX, 수원→서울 31분), `여객_하_(서울-수원)_NEW`(ID 0120202, 하행 KTX, 서울→수원 36분 30초, 영등포 2분 정차). 진로는 모두 역 진로표에 있는 값입니다(영등포 상행 출발 `3C_B619T2T` 포함).
- `전동_하_(청량리-수원)_NEW`(ID 0129103), `전동_상_(수원-청량리)_NEW`는 이름만 사진에서 확인했고 행은 미확인이라, 이 시뮬레이터의 전역정차 운행시분으로 채웠습니다(`source:'simulator'`).
- 목록에 이름만 보인 나머지 9개(구로차량기지, 모터카_상, 휴일, 고속_하, 화물_하, LINEUP_하, 전동차(상행), 전동-3, 여객_상)는 내용을 모르므로 넣지 않았습니다. 사진을 주시면 그대로 추가하거나, MA007_01에서 직접 등록할 수 있습니다.
- 열차종별에 사진의 `무궁화호`, `화물`을 추가했습니다(무궁화호=저상홈, 화물=승하차 없음).

- 기존 간이 `열차운행패턴선택` 창(운행구간만 고르던 것)과 MMI의 열차운행패턴 관리 "미구현" 창.

## v0.28.1 — 사용자 확인으로 고친 것
- **Ctrl+C**는 창을 띄우지 않고 열차만 기억한다. **Ctrl+V**를 누르면 [TRN_ADD] 온라인 열차 스케줄 추가가 복사한 열차의 경유역·시각·진로를 그대로 채운 채 열리고 열차번호만 빈칸이다(사진: K0011 계열 지하청량리 11:00:00 → 수원 12:37:00). 시발시각을 바꾸면 동기화로 전체가 움직인다.
- **Ctrl+A**(열차생성)는 [PTN_LOAD]를 연다. 처음에는 열차패턴리스트·경유역 정보가 비어 있고(열차종별 KTX, 열차방향 하행), [열차패턴조회]를 눌러야 목록이 나온다.
- **이전화면 / 다음화면**은 누를 때마다 그래프를 한 화면(현재 시간 범위)만큼 왼쪽(이전 시각) / 오른쪽(다음 시각)으로 옮긴다.
