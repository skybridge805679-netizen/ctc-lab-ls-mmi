# 연동 규칙 확인 요청 (오버랩 · 접근쇄정)

실물 장비 관찰로 연동 자료의 오류가 드러나고 있다. 이 문서는 지금 규칙의 근거, 확인된 결과, 아직 확인하지 못한 진로 조합을 적는다.
실물 연동도표(진로표)가 있으면 아래 목록 전체를 한 번에 확정할 수 있다.

## 지금 규칙의 근거

| 항목 | 지금 방식 | 근거 |
|---|---|---|
| 접근쇄정 시간 | 장내 90초 · 출발 30초 | 대피 대본 · 구술 8번 (확인됨) |
| 접근쇄정이 걸리는 조건 | 신호기 외방의 가까운 열번창 2칸(출발은 승강장 포함)이나 회로 2개에 열차가 있을 때. 없으면 즉시 해정 | 정의만 교재, 구간 범위는 배선에서 추정 |
| 입환표지 취소 | 쇄정 없음 | 자료 없음 |
| 오버랩 | 실물·대본으로 확인한 6개 + 규칙으로 계산한 것 | 규칙: 「도착선의 출발 진로들이 공통으로 쓰는 전환기」 — 실물과 맞는다는 보장이 없다 |
| 전환기 방향(진로별 정위·반위) | 배선도를 따라가며 계산 | 실물 진로표와 대조하지 않음 |

11-11 확인에서 후보 8개 중 1개만 실제 오버랩이었다. 가까운 전환기라고 해서 걸리는 것도 아니었다(금천구청 57호 · 영등포 57호는 출발신호기 바로 앞인데 걸리지 않음).
그래서 **오버랩은 배선만으로 계산할 수 없고 도착선마다 정해진 것**으로 본다. 연동도표는 구할 수 없으므로, 아래 추론 규칙으로 확인 횟수를 줄인다.

## 추론 규칙

1. **오버랩은 도착선(출발신호기)마다 하나다.** 같은 선으로 들어오는 장내 진로는 모두 같은 오버랩을 가진다. (예: 안양 1A-2T에서 확인한 55호는 1B-2T에도 적용)
2. **오버랩은 출발신호기에서 이어지는 구간이다.** 가장 가까운 전환기가 걸리지 않으면 그 선에는 오버랩이 없다. 걸리면 그다음 전환기 하나만 더 본다.
3. 걸려도 막을 진로가 없는 전환기는 확인할 필요가 없다 (연습에서 차이가 나지 않는다).

이 규칙으로 도착선 52개 가운데 이미 정해진 것과 확인이 필요 없는 것을 빼면, **도착선마다 한 쌍**씩 확인하면 된다.

이미 정해진 도착선: 용산 4T(상) 2A-4T: 없음 / 용산 2T(상) 2B-2T: 없음 / 영등포 2T(하) 1A-2T: 없음 / 금천구청 3T(하) 1B-3T: 없음 / 금천구청 5T(상) 2A-5T·2B-5T: 없음.

## 접근쇄정에서 확인하면 좋은 것

1. 접근하는 열차가 없을 때 장내신호를 취소하면 바로 해정되는가, 그래도 시간이 걸리는가.
2. 열차가 장내신호기 외방 몇 번째 폐색에 있을 때부터 90초가 걸리는가 (지금: 가까운 열번창 2칸).
3. 입환표지(21 · 51 …)를 취소할 때도 쇄정 시간이 있는가 (지금: 없음).
4. 쇄정 중에 같은 신호기로 다른 진로를 내면 나오는 MMI 문구.
