# 연동 규칙 확인 요청 (오버랩 · 접근쇄정)

실물 장비 관찰로 연동 자료의 오류가 드러나고 있다. 이 문서는 지금 규칙의 근거, 확인된 결과, 아직 확인하지 못한 진로 조합을 적는다.
실물 연동도표(진로표)가 있으면 아래 목록 전체를 한 번에 확정할 수 있다.

안양 2번선 · 용산 3번선은 있는데 못 찾았다). 그래서 지금은 이렇게 둔다.

- **본선(제 방향) 도착**: 실물에서 확인한 오버랩만 둔다. 계산하지 않는다.
- **부본선 도착**: 확인된 5건(금천구청 1 · 6번선, 영등포 1번선, 안양 1번선, 용산 6번선)이 모두 계산 규칙대로여서 계산을 유지한다.
- **대향진로**: 같은 선에 반대 방향에서 들어오는 진로는 함께 서지 못한다 (전 역 공통).

## 추론 규칙

1. **오버랩은 도착선(출발신호기)마다 하나다.** — 안양 2번선에서 1A-2T · 1B-2T 둘 다 55호로 확인되어 성립.
2. **오버랩은 출발신호기에서 이어지는 구간이다.** 가장 가까운 전환기가 걸리지 않으면 그 선에는 오버랩이 없다. 걸리면 그다음 전환기 하나만 더 본다.
3. 걸려도 막을 진로가 없는 전환기는 확인할 필요가 없다.

이미 정해진 도착선: 용산 3T(하) 1B-3T: 있음(51호) / 용산 4T(상) 2A-4T: 없음 / 용산 2T(상) 2B-2T: 없음 / 영등포 2T(하) 1A-2T: 없음 / 영등포 4T(상) 2A-4T·2B-4T: 없음 / 금천구청 2T(하) 1A-2T·1B-2T: 없음 / 금천구청 3T(하) 1B-3T: 없음 / 금천구청 5T(상) 2A-5T·2B-5T: 없음 / 안양 2T(하) 1A-2T·1B-2T: 있음(55호) / 안양 1T(하) 1A-1T·1B-1T: 있음(55호) / 안양 3T(하) 1B-3T: 없음 / 군포 1T(하) 1A-1T·1B-1T: 없음.

## 접근쇄정에서 확인하면 좋은 것

1. 접근하는 열차가 없을 때 장내신호를 취소하면 바로 해정되는가, 그래도 시간이 걸리는가.
2. 열차가 장내신호기 외방 몇 번째 폐색에 있을 때부터 90초가 걸리는가 (지금: 가까운 열번창 2칸).
3. 입환표지(21 · 51 …)를 취소할 때도 쇄정 시간이 있는가 (지금: 없음).
4. 쇄정 중에 같은 신호기로 다른 진로를 내면 나오는 MMI 문구.
