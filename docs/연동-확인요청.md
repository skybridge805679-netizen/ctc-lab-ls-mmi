# 연동 규칙 확인 요청 (오버랩 · 접근쇄정)

2026-11-11 용산 확인(2A-7T ∥ 4B-B610T, 1B-3T 중 2A-5T 거부 · SW-52)으로 연동 자료에 오류가 있었음이 드러났다.
이 문서는 지금 규칙이 무엇을 근거로 하는지와, 실물 장비에서 확인하면 좋은 진로 조합을 적는다.
실물 연동도표(진로표)가 있으면 이 목록 전체를 한 번에 확정할 수 있다.

전 역에서 찾았다. **지금 시뮬레이터에서는 두 진로가 함께 선다.** 실물에서 「먼저」를 설정한 뒤 「다음」을 냈을 때 거부되는지,

## 접근쇄정에서 확인하면 좋은 것

1. 접근하는 열차가 없을 때 장내신호를 취소하면 바로 해정되는가, 그래도 시간이 걸리는가.
2. 열차가 장내신호기 외방 몇 번째 폐색에 있을 때부터 90초가 걸리는가 (지금: 가까운 열번창 2칸).
3. 입환표지(21 · 51 …)를 취소할 때도 쇄정 시간이 있는가 (지금: 없음).
4. 쇄정 중에 같은 신호기로 다른 진로를 내면 나오는 MMI 문구.
