# v0.39.71 릴리스 복구

첨부된 v0.39.70 Windows CI 로그는 `oral-line.test.cjs`의 문서 일치 검사에서 실패했다. 생성된 문자열은 LF, Windows 체크아웃의 기존 문서는 CRLF였으며 엄격 비교가 이를 본문 차이로 처리했다. 테스트는 비교 전에 저장소 문서를 덮어쓰기도 했다.

생성기에 `--check`를 추가했다. 두 구술 문서를 CRLF→LF로 정규화해 비교하고 원본 파일은 쓰지 않는다. LF·CRLF 모두 통과하고, 어느 문서든 본문을 바꾸면 실패하며 바뀐 파일을 보존하는 회귀 검사를 추가했다. `--output-dir`는 임시 디렉터리에 시험용 문서를 생성하는 데 사용한다.

워크플로의 경로 필터에 생성기와 두 문서를 추가했다. 버전은 0.39.71이며 0.39.70까지의 제품 변경을 포함한다. Windows/macOS 설치 파일은 기존 CI의 모든 검사 통과 후 게시된다. 이 작업 환경에서는 GitHub Actions API 조회가 Forbidden으로 거부돼 원격 실행 결과의 직접 확인에 제약이 있다.
