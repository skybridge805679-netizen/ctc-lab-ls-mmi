# v0.39.5 검수 결함 수정

- 추가 LS 창의 연결·새로고침이 다른 창의 로그 재생을 해제하지 않도록 했습니다. 재생 중에는 엔진이 실시간 조작을 계속 거부합니다.
- 세션을 성공적으로 열면 이전 시간표의 실행 취소·다시 실행 이력을 지웁니다. 잘못된 세션을 열었을 때는 기존 이력을 보존합니다.
- 구 시험·실습 시간 설정 메뉴를 제거한 상태에 맞춰 네이티브 FTS 검사를 갱신했습니다.
- 분리 창 브라우저 검사는 시작과 새로고침 후 시험용 시간표를 명시적으로 넣습니다.
- 버전을 0.39.5로 올려 기존 0.39.4 다운로드와 구별합니다.

검증: Node 175개 통과, 전체 Linux Electron 데스크톱 검사 통과, 분리 창 브라우저 1440/1920px 통과. Linux 패키지 129개 파일의 소스 일치와 내부 버전 0.39.5를 확인했습니다. macOS/Windows 설치 파일 생성과 검증은 main 푸시 후 CI에서 수행합니다.
