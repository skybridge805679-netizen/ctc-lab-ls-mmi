# LS 벡터 재작성 — v0.8.0

## 목적
PDF 이미지 위에 클릭 영역을 덧그리던 LS를, 같은 상태·진로 시스템 위에서 **벡터로 새로 그린 화면**으로 바꾼다. 화면 폭을 모두 쓰고 가운데 정렬하며, 의미 없는 장식은 넣지 않는다.

## 구성
| 파일 | 역할 |
|---|---|
| `simulator/wiring.js` | 취급역 구내 추적 선로(rails), 전환기 연결(links), 신호기. 로컬 좌표는 PDF 5760px 기준과 거의 1:1 |
| `simulator/wings.js` | 중간역·역간 구간. `tools/extract-wings.py`가 생성 |
| `simulator/ls-view.js` | SVG 렌더러. `render(station, wiring, core, state, {left,right})` |
| `simulator/app.js` | 헤더 버튼, 진로·쇄정 현황판, 클릭 처리 |
| `tools/extract-wings.py` | 원본 이미지에서 칸·승강장·이름판·라벨·신호기 추출(OpenCV + RapidOCR) |

## 그리는 방식
- 구내: 추적된 선로(막대), 전환기 연결(대각선), 전환기 이름표, 신호기(원 또는 사각 램프+마스트+이름). 전환기 이름표는 클릭할 수 없고 반위는 주황, 수동 쇄정은 붉은 테두리, 오버랩 쇄정은 보라 점선 링.
- 중간역·역간: 원본의 궤도 칸(이름 포함), 교차·연결 도형, 승강장(주황/청록), 이름판(역 이름은 `map.view.intermediate` 순서), 라벨, 신호기.
- 진로선: 설정 녹색 실선, 점유 적색, 접근쇄정 주황 점선. 접근 열차 파란 마커.
- 구내 신호기 겹침은 같은 선로·같은 쪽에서 64 단위 간격으로 밀어 해소하고, 전환기 이름표는 신호기 글자와 겹치지 않는 자리를 찾는다.
