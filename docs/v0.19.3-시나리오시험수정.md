# v0.19.3 — mmi-scenarios.browser.test.py 실패 수정

main `8a863f4`에서 해당 파일을 직접 실행해 실패를 재현했다. 실패 지점은 구술 체크 직후 `#scStatus`에 「합격」이 나와야 한다는 검사였다. 실제 화면은 「조작·구술 완료 — 열차 이동과 도착을 기다리고 있습니다」를 표시했다.

현재 시나리오는 조작·구술뿐 아니라 이동 대기열과 열차 이동이 끝나야 합격한다. 기존 시험은 이 동작을 반영하지 않았으며, 앞선 v0.19.3의 브라우저 검증 10종에도 이 파일은 포함되지 않았다.

시험을 가상시계와 명시적 tick으로 진행하도록 바꿨다. 실제 시간 경과에 기대던 입선·출발 대기를 제거하고 다음 조건을 확인한다.

- 진로를 설정해도 열차가 즉시 목적지로 옮겨지지 않는다.
- 조작·구술 체크를 마쳐도 이동이 남아 있으면 합격 표시·합격 로그가 없다.
- 이동이 끝나면 모든 작업이 `done` 상태이고, 취소로 시험을 통과하지 않는다.
- 해당 열차들의 열번과 모의 점유가 정리된 뒤 합격 표시와 로그가 남는다.
- 다른 시나리오를 다시 시작할 수 있다.

프로그램의 합격 조건이나 운행 동작은 변경하지 않았다.

1440×1000·1920×1080에서 수정한 시험을 통과했다. 관련 `scenario-motion`·`mmi-scenario-cast` 브라우저 시험과 `scenarios.test.cjs`·`scenario-motion.test.cjs`도 통과했다. 모바일 검증 없음.

```sh
python simulator/mmi-scenarios.browser.test.py
node --test simulator/scenarios.test.cjs simulator/scenario-motion.test.cjs
```
