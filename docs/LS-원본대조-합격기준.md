# LS 화면 원본 대조 합격 기준

한 역을 「완벽하게」 고쳤다고 말하려면 아래 항목을 **모두** 통과해야 한다.
기준 자료는 원본 LS 슬라이드(`simulator/assets/stations/slideN.png`)이고, 필요하면 PDF 전체노선 배선도를 함께 본다.
위치 비교는 원본 슬라이드 좌표 × (1600 / 슬라이드 폭)으로 하고, **SVG 좌표로 숫자를 재서** 확인한다. 스크린샷 눈대중으로 판정하지 않는다.
허용 오차는 가로 ±6px(1600 기준)다. 세로는 역 공통 간격 규칙을 따른다(아래 14번).

## 0. 절차

- [ ] 원본과 현재 화면을 같은 배율로 **왼쪽·가운데·오른쪽 세 구간** 확대해서 나란히 놓고 본다.
- [ ] 원본 슬라이드에서 흰 칸을 줄마다 픽셀로 읽어(`(시작, 끝)`) 표로 만든다.
- [ ] 아래 1~15번을 차례로 숫자로 확인한다. 하나라도 어긋나면 불합격이다.
- [ ] 지적받은 것만 고치지 않는다. 같은 종류의 다른 요소(같은 역의 다른 선로전환기, 다른 승강장 등)도 모두 확인한다.
- [ ] 단위 시험(`npm test`)과 LS e2e(`ls-train-windows-rule`, `ls-platform-labels`, `ls-context`, `all-stations-layout`, `ls-layout`, `continuous-overview`, `design`)가 통과한다.

## 1. 회로 칸 (선로 위 흰 막대)

- [ ] 줄마다 칸 개수가 원본과 같다(빈 이름 칸·승강장 칸 포함).
- [ ] 칸마다 시작·끝 x가 원본과 ±6px 안이다.
- [ ] 칸 이름이 원본 칸 안에 원본 글자로 적혀 있다(「52BT · Y1T」처럼 붙은 이름 없음).
- [ ] 회로 경계마다 일정한 틈(7px)이 있다. 같은 회로 조각·승강장 칸과 그 nT 사이에는 틈이 없다.
- [ ] 화면 끝까지 가는 회로는 화면 끝부터(또는 끝까지) 그려진다. 빈 선로 조각을 덧붙이지 않는다.

## 2. 선로·꺾임

- [ ] 꺾이는 꼭짓점(사선의 시작·끝)이 원본 위치에 있다.
- [ ] 꺾여 들어온 선로의 꼬리·틈이 원본과 같다(꼬리 뒤 틈인지, 칸까지 이어지는지).
- [ ] 사선의 방향(／, ＼)이 원본과 같다.
- [ ] 꺾인 곳 바깥으로 튀어나온 조각이 없다.

## 3. 선로전환기

- [ ] 선로전환기마다 틈(정위·반위 표시)이 **사선이 본선과 만나는 자리**에 있다.
- [ ] 사선이 본선에 그냥 붙어 있지 않다(틈이 보인다).
- [ ] 선로전환기 번호가 그 선로전환기 바로 옆, 원본과 같은 쪽(위/아래)에 있다.
- [ ] 반위로 돌렸을 때도 그림이 원본 배선대로 이어진다.

## 4. 건넘선·시저스

- [ ] 건넘선 두 끝 x가 원본과 같고 방향이 같다.
- [ ] 시저스는 X자로 보인다(기둥처럼 길쭉하지 않다).
- [ ] A/B 부분 번호(21A·21B 등)가 원본 쪽에 있다.

## 5. 신호기

- [ ] 모든 신호기가 원본 위치(빨간 등 위치)에 있다.
- [ ] 기둥(마스트)이 회로 사이 틈에 선다.
- [ ] 등 몸체가 건넘선·사선·다른 신호기·폐색 표식·승강장과 겹치지 않는다.
- [ ] 신호기 이름이 원본과 같은 쪽에 있다.

## 6. 입환표지

- [ ] 신호기와 같은 기준(위치·틈·겹침 없음)을 지킨다.
- [ ] 건넘선 사선을 가리지 않는다. 가리면 그 구간의 가로 배율(원본 위치)을 조정한다.

## 7. 승강장 (주황·하늘색 막대)

- [ ] 개수·위치가 원본과 같다.
- [ ] 같은 역의 구내 승강장은 원본처럼 같은 크기로 그려진다. 혼자 작거나 비뚤어진 것이 없다.
- [ ] 승강장 열번창과 같은 폭·같은 x에 있다.

## 8. 승강장 열번창·nT

- [ ] 승강장 열번창 x가 원본과 같다.
- [ ] nT 번호가 열번창 오른쪽 칸에 있다.

## 9. 열번칸 (떨어진 흰 상자)

- [ ] 개수가 원본과 같고, 칸마다 x가 원본과 ±6px 안이다.
- [ ] 원본과 같은 쪽(선로 위/아래)에 있다.
- [ ] 다른 선로를 건너지 않고, 신호기·표식·글자와 겹치지 않는다.

## 10. 폐색 표식 (번호 캡슐)

- [ ] 번호·개수가 원본과 같다.
- [ ] 기둥(⊢)이 회로 경계(또는 화면 끝)에 선다.
- [ ] 원본과 같은 쪽(위/아래)과 같은 방향(기둥 왼쪽/오른쪽)이다.

## 11. 중간역 이름판·고상홈

- [ ] 이름판이 원본 위치(그 역 열번칸 위)에 있다.
- [ ] 고상홈 표시가 정차 회로에 붙어 있다.

## 12. 문구·안내 상자

- [ ] 원본에 있는 문구(기지선 이름 등)가 원본 위치에 있다.
- [ ] 원본에 없는 표기(하2선·상1선 등)가 없다.

## 13. 화면 이동 화살표

- [ ] 원본의 화살표(방향 글자·이웃 화면)가 모두 있다. 없으면 보고서에 적는다.

## 14. 세로 간격

- [ ] 선로 순서와 줄 사이 상대 간격이 원본과 같다.
- [ ] 절대 간격은 역 공통 규칙을 따른다. 원본과 다르면 보고서에 적는다.

## 15. 겹침·잘림 (자동 검사)

- [ ] `all-stations-layout`, `ls-context`, `ls-layout` 검사에서 이 역의 겹침·잘림이 0건이다.

## 보고서

- 항목별로 통과·불합격과 측정값(원본 x / 현재 x)을 적는다.
- 고치지 못한 것은 이유와 함께 적는다. 통과로 적지 않는다.
