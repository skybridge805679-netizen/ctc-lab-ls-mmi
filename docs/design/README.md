# LS v0.10 디자인 참조

`ls-v0.10-imagegen-reference.png`는 2026-10-21 `image_gen.imagegen`으로 생성했다. 입력은 `docs/preview-v0.9.0-guro.png`였으며, 실제 앱에 사용하는 이미지가 아니다.

요청한 방향: 기존 구로역의 선로와 관할 중간역을 유지하고, 동일한 선로 굵기·가는 궤도 경계·겹치지 않는 번호·신호기·승강장·헤더 체계를 갖춘 평면 벡터 UI 시안. 겹친 칸 테두리와 전환기 번호 상자를 없애고 하나의 공학 도면처럼 정리하도록 요청했다.

생성 결과의 글자와 배선은 정확성의 근거로 삼지 않는다. 실제 연결·번호는 원본 PDF와 `wiring.js`/`schematic-details.js`, 상태는 `core.js`가 결정한다. 앱은 PNG 대신 코드로 만든 SVG 요소를 렌더링한다.
