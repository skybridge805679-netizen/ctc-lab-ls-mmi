## 다른 역에 함께 적용된 것

- overrides로 원본 위치를 직접 적은 칸은 꺾임 꼭짓점에 끌려가지 않고 원본 끝 그대로 그린다. 그래서 다음 칸이 원본과 같아졌다.
  - 의왕 21AT 끝 371→386 (원본 388), 23AT 393 (원본 392)
  - 수원 33T 1282→1286 (원본 1285)
  - 구로 51BT 끝 773→788 (원본 788)
  - 안양 6T 끝 칸 1142→1152 (원본 1152)
  - 금천구청 54T 757 (원본 757)
