# v0.19.2 — 전 역 진로 경합 대조와 공통 정위 쇄정 수정

안양 `4C-B660T`·`4A-B984T`만 예외로 허용하던 판정을 공통 규칙으로 바꿨다. 원본 배선을 추적한 선로 구간이 서로 겹치지 않고, 공유하는 전환기 그룹을 모두 정위(N)로 유지하면 함께 설정한다. 새로 허용되는 조합은 15개 역에 걸쳐 1,541쌍이다. 안양 실물 확인 조합을 포함하면 공통 정위 쇄정을 사용하는 조합은 1,542쌍이다.

## 대조 근거와 적용 범위

- [실무5 최종판](../references/manuals/실무5_최종판_실전대본중심.pdf#page=75) PDF 75쪽·책자 67쪽, 「12. 진로제어 단계와 쇄정」: 진로요청 시 선로·전환기·대향 진로 조건을 검사하며 전환기를 **제어된 위치에 쇄정**한다. PDF 76쪽·책자 68쪽은 접근쇄정·오버랩 취급과 전환기 그룹을 설명한다.
- [원본 배선 추적 모델](../simulator/wiring.js)의 연결과 궤도 구간을 대조했다. 건넘선 양 끝의 전환기는 같은 그룹 번호를 쓴다. 서로 다른 평행 직선 선로를 지나는 진로가 그룹 번호를 공유한다는 사실만으로 선로가 겹치거나 전환기가 움직이는 것은 아니다.
- [안양 실물 LS 확인](v0.19.1-안양동시진로.md): `4C-B660T`·`4A-B984T`는 공유 선로 없이 53번을 정위로 요구한다. 사용자가 실제 LS에서 동시 설정 가능함을 확인했다.
- 금천구청 26·54번 오버랩과 영등포 4B 해정 조건 등 [문서화한 연동 조건](../simulator/interlocking.js)은 별도로 적용한다.

교재 문구만으로 1,541쌍의 실설비 동시 취급을 각각 입증한 것은 아니다. 이번 대조는 제공된 배선 추적 데이터와 명시된 쇄정 조건에서 발견한 공통 과잉 차단을 수정한 것이다. 제공되지 않은 실설비 연동표·측면 방호·추가 오버랩 조건은 여전히 실물 확인 대상이다.

## 판정과 보호

동일 신호의 다른 진로, 공유 선로 구간, 반위(R)를 공유하는 진로, 서로 다른 전환기 방향, 방향 누락, 문서화된 오버랩 충돌은 계속 차단한다. 같은 반위 공유까지 일반 허용하지 않는다. 같은 정위 공유를 허용하더라도 한 진로만 통과·해정한 동안 남은 진로가 사용하는 전환기는 계속 쇄정한다. 접근쇄정·고장·TTB·AUTO의 역방향 진로 제한도 기존 검사를 거친다.

LS·MMI·AUTO·시나리오는 모두 같은 코어의 경합 판정을 사용한다. 기존 시험에서 잘못된 경합을 전제로 한 두 사례는 실제 공유 선로·건넘선 충돌 사례로 교체했다. 자동제어의 장애 등록·재시도 검사는 유지한다.

## 검증 결과

656개 진로의 가능한 모든 역내 조합 **19,392쌍**, 설정 순서를 바꾼 **38,784회**를 검사했다. 허용 11,749쌍·차단 7,643쌍이며, 설정 순서 비대칭·공유 선로 허용·설정 후 전환기 요구 방향 위반·거절 시 기존 현장 상태 훼손은 0건이다.

정위 공유 1,542쌍은 양방향 순서로 별도 생명주기 검사 **3,084회**를 수행했다. 두 열차의 진입·동시 점유·한쪽 통과 후 나머지 점유 유지·마지막 진로까지 전환기 보호·최종 해정 후 전환 가능을 검사한다.
