# v0.25.3 — 원본 비율로 성균관대·화서 사이 여백 복원

0.25.2에서는 전체노선 PDF의 역명판·승강장 좌표와 균등 분할한 회로 칸을 분리 화면에도 적용했다. 원본 PPT의 별도 화면과 가로 비율이 달라 성균관대·화서가 가운데 쪽으로 몰리고, 역명판과 승강장 표시도 과도하게 커졌다.

PPT 슬라이드 18의 실제 좌표로 교정했다. 성균관대는 화면 가로 약 35%, 화서는 약 85% 위치에 놓인다. 역명판은 원본처럼 화면 폭의 약 9%로 표시하여 두 역 사이에 여백을 남긴다. 역명판과 선로 사이의 여백도 확보했다. 승강장의 가로 폭·위치와 선로로부터의 간격은 원본 기호를 기준으로 배치했다.

39개 회로는 원본의 각 사각형 폭을 사용한다. 상선 쪽의 긴 칸과 짧은 칸도 유지한다. 열번창과 폐색 번호는 같은 회로의 좌표를 따라가며 정보·식별자는 바꾸지 않는다. 역간 프리셋에 따라 들어왔던 수원 진입 회로 B1036T·B714T·B709T·B1035T는 수원 화면에서 계속 표시한다. 의왕~수원은 원본 별도 화면의 끝 회로까지만 표시한다. 엔진의 회로 연결·열번 데이터는 변경하지 않았다.

감시 전용 동작은 유지한다. CCM·일괄정지·설비제어·열번 편집은 없으며 실시간 열번·점유와 속성 조회를 제공한다.

## 검증

- 단위 시험 74개: 열번창·폐색 번호 누락/중복 방지와 수원 진입 회로의 표시를 포함한다.
- 1920·1440·960 폭에서 역명판의 실제 위치·폭·두 역 사이 여백을 측정하고 열번·점유 동기화와 감시 화면 조작 차단을 확인했다.
- 16개 LS 화면의 글자 겹침·잘림, 276개 열번창·우클릭 메뉴·Overview와 화면 끝의 수평 연결을 검사했다.
- Linux 실제 Electron 패키지를 실행했다. Windows x64·Mac ARM64·Linux의 런타임 파일을 소스와 대조했다. Windows·Mac 네이티브 설치 파일은 GitHub Actions에서 검증·생성한다. 모바일 검증은 포함하지 않는다.
