### 장내·출발 규칙 (5개 역에서 도출, 나머지 역은 미검증)
- 장내신호기: 도착지는 구내 선로(경계 `B…T` 제외).
- 출발신호기: 도착지는 경계 궤도이며 번호의 짝·홀이 진행 방향과 맞아야 한다(짝수=하행·오른쪽, 홀수=상행·왼쪽). 청량리의 `A1T`·`AT`, `Y1T`는 경계로 취급.
- 이 규칙은 근거 문서가 아니라 사용자 목록에서 귀납한 것이다. 복잡한 역(용산·영등포·수원 등)에서 맞는지는 확인되지 않았다.

### 입환 신호기
도출 진로가 실제 메뉴보다 많다(예: 서울 55-B901T·B902T, 지하서울 52-B072T·53-B067T). 실제로 허용되는 진로는 연동 조건이라 배선만으로 가릴 수 없다.

## 확인이 필요한 항목
1. 서울 `54 - RT_52_BT`: 신호기 번호와 진로 이름이 다르다. `RT_54_BT`의 오타로 보이나 확인 필요.
2. 청량리 `4B`: 시뮬레이터에는 있으나 목록에 없음. 누락인지 진로가 없는 신호기인지 확인 필요.
3. 지하서울 `3A`: 목록에는 `RT_3A_B065T`뿐인데 매뉴얼 인쇄 p.6의 MMI 목록에는 `3A_B070T`도 있다. LS 팝업에 `RT_3A_B070T`가 실제로 뜨는지 확인 필요(현재 시뮬레이터는 3A-B070T를 제공).
4. 제목 「지하청량리」는 청량리로 처리했다.

## 남은 9개 역(용산~수원)의 규모
장내·출발 진로 190개(규칙으로 추정), 입환 신호기 88개·후보 진로 258개. 입환은 사용자 확인 없이는 확정할 수 없다.

## 제안
1. 장내·출발은 위 규칙으로 초안을 만들고, 역별 후보 목록을 사용자가 **삭제만** 하며 검수한다.
2. 입환은 후보 목록을 제시해 틀린 것만 지우게 하거나, 실제 LS 팝업 캡처를 받아 OCR로 읽는다(손 입력보다 오타가 적다).
3. 목적지가 궤도 칸 이름(BT, Y1T 등)인 진로를 위해 구내 궤도 칸 이름을 추출 데이터(`wings.js`와 같은 방식)에 추가한다.
4. 확정된 목록은 진로 메뉴의 허용 목록(화이트리스트)으로 저장하고, 목록에 없는 도출 진로는 메뉴에서 숨긴다.
