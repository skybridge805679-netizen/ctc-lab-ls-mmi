# v0.39.4 통합 배포

사용자 요청에 따라 v0.39.3과 표시 수정의 통합본 `afcc445`를 0.39.4로 올려 main에 반영합니다. 앞서 테스트 브랜치에만 두었던 배선·오버뷰·회로명 복원이 이번 버전에 포함됩니다.

- 사다리꼴 네 조각의 X 교차부, 사선 끝단 간격과 직각 모서리 정리.
- 청량리–영등포 2줄, 구로–수원 2줄, 노량진–금천구청 1줄의 원본 구간 오버뷰와 창 크기에 맞춘 배치.
- 15개 역·역간 화면 3개의 원본 목록 대조 및 11개 역 회로명 누락·오독·중복 수정.
- v0.39.3의 온라인 스케줄 ID 관리, v0.39.2의 의왕 건넘선 분리, 정식 v0.39.1의 진로 선택 수정 유지.

통합본의 Node 테스트 174개, 화면 목록·배치 검사 108건과 글자 픽셀 검사 168건, 스케줄 ID 관리 및 오버뷰 브라우저 검사, Linux 데스크톱 전체 검사가 통과했습니다. 이번 배포 변경은 버전과 문서이며 실행 소스는 통합 검증본과 동일합니다. 버전 변경 후 Node 테스트와 세 플랫폼 패키지의 버전·소스 일치를 다시 확인합니다.
