# v0.25.1 — 역별 배치를 복원하고 선로만 창 끝까지 연장

15개 취급역의 배선·신호기·열번창·전환기 배치를 0.24.0(`be0f6ca`)으로 되돌렸다. 0.25.0의 역간 높이 제약과 행별 재배치 계산은 제거했다. 같은 역 안에서 사용하는 좌표 변환과 조작 위치는 안정적인 이전 방식으로 복원했다.

실제 본선 끝에서 좌우 창 끝까지의 **수평 연장**만 유지한다. 역 안의 건넘선·분기·원래 높이 변화는 그대로 두고, 화면 연결을 위해 곡선·대각선·계단을 덧붙이지 않는다. 각 역의 선로 높이를 우선하므로 이웃 LS 창과 높이가 다를 수 있다.

창의 비율에 맞춰 배선 전체를 표시한다. 비례 축소로 생기는 좌우 여백까지 본선을 수평 연장하여 실제 창 끝에 닿게 한다. SVG를 비균등 확대하여 신호기·열번창을 찌그러뜨리지 않는다. 연장선은 끝 회로의 점유·진로 색을 따르지만 회로·전환기·연동 조건을 추가하지 않는다. 금정의 비취급 통과 본선도 유지한다. 역 방향 안내는 상단에 두어 경계 선로 이름과 겹치지 않게 했다. 청량리~지하서울의 지하 구간은 원본 배선의 1T·2T 구분에 따라 **하선 · 1선 / 상선 · 2선**으로 방향과 번호를 함께 표기한다. 서울역의 지하 구간 쪽 경계도 같은 표기를 사용한다. 일반선·전동선의 상하 1·2선 구분은 유지한다.

**LS +**, **실습 화면 → LS 추가 창 → 역** 기능은 유지한다. 각 LS는 선택역을 따로 기억하며 같은 독립 엔진을 제어한다. 기존 MMI·그래프·알람, 시나리오 자동 진행, 수동 열번 즉시 이동, A/B 전환기 조작·쇄정·세션 저장 동작은 유지한다.

## 검증

- 단위 시험 68개 통과. 모든 역의 독립적인 좌표 변환·수평 경계 연장·실제 회로 점유색을 확인했다.
- 1920×1080·1440×1000·960×720에서 14개 인접 화면 경계의 연장이 각 창의 좌우 끝에 1픽셀 이내로 닿으며, 모두 높이 변화 없는 수평 직선임을 확인했다. 역 사이 높이 일치는 검사 대상에서 제거했다.
- 15역 정위·반위 상태에서 글자의 겹침·잘림을 1440·1920 폭으로 검사했다. 원본 괄호 표식·기지 문구·열번창도 검사했다. 데스크톱 6개 창 크기 × 15역에서 SVG 비율·도구 모음·확인창 조작 영역을 확인했다.
- 모든 역의 표시 전환기를 실제 클릭하여 제어하고, 체크 없이 시나리오 진행·시간표 JSON 저장/열기·실행 취소/다시 실행을 확인했다.
- Linux 실제 Electron에서 독립 엔진·시나리오 이동·창 닫기/재열기·세션 복구·추가 LS 두 개의 독립 역 선택과 공통 엔진 제어를 확인했다. 추가 LS의 CCM 조작이 주 LS에도 반영되고 기존 MMI를 재사용하는지 검사했다.
- Apple Silicon Mac·Windows x64·Linux 앱 패키지를 만들고 전체 런타임 파일을 원본 소스와 대조했다. Linux 패키지의 실제 실행 시험도 통과했다. Mac·Windows 네이티브 실행 및 최종 설치 파일 생성은 main 반영 후 GitHub Actions에서 수행한다.

모바일 화면과 모바일 검증은 포함하지 않는다.
