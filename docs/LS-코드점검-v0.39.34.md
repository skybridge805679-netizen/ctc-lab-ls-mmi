# LS 화면 코드 점검 (v0.39.34)

`tools/audit-ls-code.cjs`로 15개 역 화면을 엔진 데이터·원본 좌표와 함께 점검했다. 단위 시험 `simulator/ui/ls-code-audit.test.cjs`가 같은 점검을 매번 돌린다.

## 점검 항목

| 항목 | 내용 |
|---|---|
| T칸 | 같은 줄에서 칸이 겹치지 않는지, 다른 회로끼리 틈이 있는지, 원본 좌표(ls-xmap)와 ±6 안인지 |
| 신호기·입환표지 | 엔진(core)·배선(wiring)·화면이 같은 목록인지, 빨간 등이 원본 ±5 안인지, 기둥이 칸 사이 틈에 서는지 |
| 선로전환기 | 배선의 모든 연결이 그려지는지, 끝점이 선로 위인지, 모든 선로전환기에 조작 번호 태그가 있는지, A/B 번호가 모두 보이는지 |
| 열번칸 | 원본 슬라이드의 열번칸이 모두 있는지, 원본 x ±6 안인지 |

## 원본 대조로 확인한 예외

- 구로 4A·54·53: 원본에서도 기둥이 칸 안에 선다.
- 노량진·영등포·금정의 승강장 칸과 nT: 한 회로라 칸은 붙고, 원본 틈이 있는 곳은 선로에 틈을 그린다.
- 노량진 원본 전사의 합친 칸(1T · 51AT 등)은 화면에서 승강장 칸과 51AT로 나눠 그린다.
- 동묘앞 21BT·21AT 끝: 원본 478, 현재 472(22BT와 틈을 공통 7px로 그림).

## 오탐으로 확인된 것

- 단동 선로전환기(지하청량리 22, 용산 22·28 등 31개)는 배선 연결선 없이 선로 꺾임으로 그린다. 조작 번호 태그는 모두 있다.
- 역간 화면(안양~금정 등)에 속한 열번칸은 그 역 화면 대상이 아니다.
