## 실습과 무관해 제외한 것
- 로그인·로그아웃·운영자 전환 (실기1 3장)
- 콘솔정보관리·콘솔제어영역 패턴관리 (실기1 4장 5절): 혼자 쓰는 시뮬레이터라 콘솔 간 제어영역 분배가 없음

## 자료가 없어 보류한 것
- 단선 구간 자동제어·교행경합 (실기3 3장 4절 차, 4장 4절 나): 선로망이 모두 복선
- 「조건이 있는 진로」는 출발진로 먼저 요구 (실기3 3장 4절 바): 어느 진로가 해당하는지 연동 자료가 없음
- 자동제안 (실기3 2장 9절 나): 교재 설명만으로는 제안 시점·화면을 정할 수 없음
- CDRS 해소안의 운행순서 변경·대피역 변경: 지금은 시각 늦추기·도착선 변경만 제안. 수동 운전정리로는 가능
- 오프라인 → 온라인 자동 로딩(매일 23:55에 모레 스케줄): 시뮬레이터는 운행일이 넘어가지 않음. [온라인 ID 예약적용]·[실시간변경]으로 올림
- 실기3 이론 구술 문항 (트리거포인트, 경합 5종, 스케줄 ID 구조, 선로용량 등): 구술 연습 문제은행은 지금 운행선관리 전용이라 별도 작업
