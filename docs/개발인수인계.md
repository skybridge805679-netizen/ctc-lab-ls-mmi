# v0.6.1: 개별 LS 화면 전환 수정

역 선택 시 전체 노선을 계속 표시하던 v0.6.0 동작을 수정했다. 15개 취급역마다 구내와 관할 중간역·역간을 포함한 표시 범위를 `network.js`의 `map.view`에 정의했다. 좌표 등록용 `referenceWindow`와 구별한다. 전체노선·PDF 페이지 조회는 별도 선택이고, 역 탭·LS/MMI 선택 목록·전체노선 역 이름을 누르면 개별 LS 화면으로 전환한다. 좌우 버튼은 인접 취급역을 선택한다. 화면 전환 시 확대율과 스크롤을 초기화하고 역별 제어 상태는 보존한다.

청량리–제기동, 동묘앞–신설동·동대문·종로5가·종로3가, 종각–시청, 서울–남영, 노량진–대방·신길, 영등포–신도림, 구로–가산디지털·독산, 금천구청–석수·관악, 안양–명학, 군포–당정, 의왕–성균관대·화서를 함께 표시한다. 지하서울·용산·금정·수원도 각각 구내와 인접 역간을 표시한다.

배경은 사용자 제공 PDF 원본을 유지한다. 사진은 화면 분할과 중간역 포함 범위를 확인하는 근거이며, 사진에만 있는 세부 표기·차번창까지 동일하게 재작성한 것은 아니다. 진로 모델의 구현 범위는 v0.6.0과 같다.

# v0.6.0 인수인계 추가

중간역·역간을 다시 자르지 말 것. `network.js`의 `map.referenceWindow`는 `wiring.js` 좌표 등록용이며 렌더러 viewBox에 넣지 않는다. LS는 `map.view.bounds`로 개별 관할 구간을 표시하며 전체 시트는 별도 조회한다. `wiring.js`의 선로 끝 접속과 명시적 연결만 그래프에 연결하고, 선로가 그림에서 교차한다는 이유로 접속시키지 않는다. 실무5 부록 A 예시를 등록할 때 해당 경로가 그래프에 없으면 로딩을 실패시킨다. 그래프 경로와 교재 예시는 실제 전체 연동표와 별개다.

검증: 기존 Node/브라우저 시험에 `node simulator/wiring.test.cjs`, `python3 simulator/wiring.alignment.test.py`, `python3 simulator/map.browser.test.py`를 포함한다. [범위와 출처](전체배선과역별제어.md).

- simulator/network.js: 전체 33개 역과 15개 제어역의 기본 진로·배선 원본 연결.
- simulator/timetable.js: 다이아·온라인 스케줄 공유 모델, 생성·수정·복사·운휴·시각 검증.

- simulator/core.js: 상태, 진로·전환기·신호기 목록, 명령 처리. 브라우저 SimCore 및 Node 모듈 공용.
- simulator/practice.js: 10개 과제 정의 및 순서·최종 상태 판정. 브라우저 SimPractice 및 Node 모듈 공용.
- simulator/app.js: LS SVG 표시, MMI 입력, 확인창, 과제·로그·기록 저장.
- simulator/index.html, style.css: 화면 구조·스타일.
- simulator/assets/underground-seoul-original.png: PPT 슬라이드 5에서 추출한 배선 이미지.
- simulator/core.test.cjs: 상태 처리 시험.

## 실행 및 시험
```sh
python3 -m http.server 8765 --directory simulator
node simulator/core.test.cjs
node simulator/practice.test.cjs
node simulator/network.test.cjs
node simulator/schedule.test.cjs
node --check simulator/app.js
```
앱 실행에 외부 패키지 설치는 필요 없음. Node는 시험에만 필요함. 브라우저 회귀 시험은 Playwright와 `/usr/bin/chromium`이 있는 환경에서 `python3 simulator/browser.test.py`로 실행한다. HTTP 서버는 시험이 임시 포트에 직접 시작하고 종료한다. 파일 직접 실행은 `--include-file` 옵션이며, 현재 클라우드 Chromium에서는 관리 정책으로 차단된다.
브라우저에서 CCM → 3A → RT_3A_B065T → 취소 유지 → 정지·해정 → MMI 설정/해정 → 전환기 조작을 직접 확인할 것.

## 주의할 현재 구현
- 접근 열차가 없는 연습만 구현하여 승인 시 즉시 해정한다. 이를 접근 중 해정 로직에 재사용하지 않는다.
- 포인트 N 초기값은 연습값이다. 자동 진로 설정이 실제 포인트 조건을 계산하는 구조는 아직 없다.
- 보호조건은 임시로 단순화되어 실제 가능한 조합도 보수적으로 막을 수 있다.
- 화면은 배경 이미지와 좌표 덧그리기 방식이다. 원본 텍스트·신호등 가림과 작은 클릭 영역을 확인해야 한다.
- localStorage의 ctclab-v03-completed는 과제 완료 번호만 보존한다. 내보내기 JSON은 현재 불러오기를 지원하지 않는다.
- archive/v0.1은 임의 배선과 타이머 문제가 있는 역사 기록, v0.2는 조작이 제한된 중간본. 현행으로 사용하지 않는다.

## 작업 진행 방식
사용자 지침: 모든 작업은 완료·검증 후 GitHub `main`에 바로 적용한다. 커밋·푸시 후 원격 `main`의 커밋이 일치하는지 확인한다. 원격 변경이 있으면 기존 작업을 보존하며 통합하고 강제 푸시는 사용하지 않는다.

기존 자료 확인 → 근거 정리 → 해당 기능 구현 → 관련 시험 → 실제 브라우저 검증 → 문서·버전 갱신 순서. 단순 설명이나 불필요한 추가 자료 요구로 사용자가 다시 작업해야 하는 상태를 만들지 않는다.

## v0.5.1 배선 교체
현행 배경은 references/diagrams/1.전체노선.pdf다. network.js의 map은 PDF 페이지·SVG 표시 영역·조작 좌표를 담는다. 이미지 자체는 assets/line-map의 원본 JPEG이며 좌표는 2048×768 기준이다. 원본 JPEG의 픽셀 크기 5760×2160과 혼동하지 않는다. core.js의 기존 경로 좌표는 레거시 데이터이며 현행 SVG 경로 표시는 map.paths를 사용한다. 배선 변경 후 `python3 simulator/map.browser.test.py`와 기존 브라우저 두 묶음을 실행한다.
