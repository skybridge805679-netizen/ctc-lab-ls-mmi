## 다른 역에 함께 적용된 것

- 원본 위치를 고정한 줄에서 화면 양 끝에 멀리 떨어진 열번칸은 높이를 따로 정한다. 한쪽 끝 장애물 때문에 반대쪽 끝 열번칸까지 선로에서 멀어지던 것을 고쳤다. 종각·영등포·금천구청·안양·금정·군포의 열번칸 몇 개가 원본처럼 자기 선로 가까이(간격 28–46 → 12–28px)로 왔다.
- 열번칸 자리를 찾을 때 폐색 표식 상자를 2px 좁혀 본다(그려진 폭에 맞춤).

## 피드백 반영 (v0.39.31)

- 오른쪽 끝 B610T·B607T가 칸 없이 화면 연결선 위 글자로만 있어 BT·YT와 붙어 보였다. 원본처럼 별도 칸으로 만들고 위치를 고정했다(1484–1594 / 1485–1600, 1485–1594 / 1487–1600).
- B606T 왼쪽 꺾임의 바깥 가로 조각이 화면 끝까지 닿지 않아 화면 연결선과 만나는 곳에 이음매가 보였다. 시작점을 화면 끝(0)에 고정했다.
