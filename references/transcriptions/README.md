# 화면 표기 대조

`intermediate-circuits.json`은 사용자 제공 `배선도(관제교육장).pptx`의 중간역·역간 선로 코드를 옮긴 기록이다. `slide`는 대조 슬라이드이며 배열은 인접 화면의 공유 접근 구간을 함께 확인했다는 뜻이다.

`strips`는 원본의 순서대로 적은 코드 목록과 PDF 배치에 등록한 좌표다. 원시 추출의 빈 칸 수에 따라 번호를 자동 부여하지 않는다. 슬라이드 18 하선의 마지막 표기는 B1031T이며 없는 B1033T를 추가하지 않았다. 복합 코드도 축약하지 않는다.

`joins`는 화면 안의 단차 연결을 그리는 표시 좌표이고, `ignoreCells`는 원시 추출에서 선로로 오인한 작은 표식 위치다. 이 기록은 실설비의 진로표·정반위 조건표를 대신하지 않으며 새로운 제어역·경로를 만들지 않는다.
