# 화면 표기 대조

`intermediate-circuits.json`은 사용자 제공 `배선도(관제교육장).pptx`의 중간역·역간 선로 코드를 옮긴 기록이다. `slide`는 대조 슬라이드이며 배열은 인접 화면의 공유 접근 구간을 함께 확인했다는 뜻이다.

`strips`는 원본의 순서대로 적은 코드 목록과 PDF 배치에 등록한 좌표다. 원시 추출의 빈 칸 수에 따라 번호를 자동 부여하지 않는다. 슬라이드 18 하선의 마지막 표기는 B1031T이며 없는 B1033T를 추가하지 않았다. 복합 코드도 축약하지 않는다.

`joins`는 화면 안의 단차 연결을 그리는 표시 좌표이고, `ignoreCells`는 원시 추출에서 선로로 오인한 작은 표식 위치다. 이 기록은 실설비의 진로표·정반위 조건표를 대신하지 않으며 새로운 제어역·경로를 만들지 않는다.

v0.13.0에서는 용산·동묘앞의 경계 칸을 보완해 67개 선로 열·238개 코드 배치를 기록한다.

`train-windows.json`은 PPT 슬라이드 2~19의 흰 열번창 276개를 기록한다. 선로 위에 겹친 흰 블록 71개도 포함한다. 원본 이미지의 사각형 좌표와 OCR 후보를 보존하며, `train-window-review.json`에는 원본을 대조한 코드·행 교정값이 있다. `slot`은 창의 고유 식별자, `code`는 원본의 연결 구간, `side`는 선로 위/위쪽/아래쪽 배치다. PDF와 PPT의 경계 코드가 다른 곳은 `anchorCode`로 현재 그림의 좌표 기준을 따로 기록한다. 이는 새 진로나 연동 조건을 추가하는 데이터가 아니다.

`python3 tools/build-train-windows.py --compile-only`로 대조 결과를 실행용 `train-windows.js`에 반영할 수 있다. `--compile-only`를 빼면 원본 PPT 미디어에서 창과 OCR 후보를 다시 추출하고 교정 기록을 적용한다.

## 고정 괄호 표식·기지 문구 (v0.18.1)

[fixed-symbols.json](fixed-symbols.json)은 전체노선 PDF 2–4쪽과 구로 사진을 대조한 파생 전사다. 구로 4쌍·노량진 2쌍의 대향 괄호와 기지 설명 5블록의 원본 좌표를 보관한다. 원본 PDF의 반복 구간은 실제 역 화면에서 한 번만 사용한다. 표식의 운영 의미·상태 전이는 미확정이며 고정 표시로 복원했다. `python tools/build-fixed-symbols.py`로 런타임 SVG 좌표 데이터를 다시 생성한다. 원본 첨부 파일은 수정하지 않았다.

## 폐색 번호 (v0.25.2)

[block-signals.json](block-signals.json)은 전체노선 PDF에서 숫자가 빠진 검은 표식에 대해 PPT 슬라이드 2~19에서 숫자 274개를 대조한 전사다. 추가 역간 화면(13·16·18)도 포함한다. 원본 기호·인접 회로 사각형 좌표, OCR 후보, 확인한 번호·회로 코드·상하 위치·기호 방향을 보관한다. `code`는 PPT의 인접 회로이고 `anchorCode`는 현재 PDF 배치의 앵커다. 금정의 우측 끝과 수원처럼 자료 판본이 다른 곳은 앵커를 명시한다. 번호를 회로 숫자나 화면 순서로 자동 생성하지 않는다. `python tools/build-block-signals.py`로 런타임 데이터를 생성한다. 원본 PPT/PDF와 운영 엔진의 진로·전환기 조건은 수정하지 않았다.

## 의왕~수원 화면의 원본 좌표 (v0.25.3)

[corridor-layout.json](corridor-layout.json)은 PPT 슬라이드 18 이미지의 실제 회로 39칸·역명판 2개·승강장 표시 4개의 좌표다. 회로 좌표와 코드는 폐색 번호 전사에서 대조한 원본 사각형을 재사용했다. 이미지 해시를 보존하며 원본 폭을 균등 분할하지 않는다. 수원 진입 회로 B1036T·B714T·B709T·B1035T는 수원 화면에서 표시한다. `python tools/build-corridor-layout.py`로 런타임 좌표를 생성한다.
