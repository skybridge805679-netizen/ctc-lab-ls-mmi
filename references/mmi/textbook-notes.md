## MMI 화면 규격 (4장)
- **진입예고열차 관리 (p.128-129)**: 운행대기 열차를 관리, 임시열차 등록으로 운행대기열 조정 → 운행순서 결정. 절차: 날짜·구간 선택 → 구간의 역 표시 → 역·신호기 선택 → [진입예고열차표시] → 등록할 열차 선택 후 등록(교재 문구 [순서변경]/[예고진입열차], 사진 버튼은 [열차등록]) → 안 보이면 [등록열차검색] → 삭제 [선택열차삭제](선택 1건) / [선택열차이전삭제](선택 이전 모두).
- **열차위치추적 (p.51-52)**: 노선·운행방향 선택 → 운행 열차번호 목록. LS 화면(모니터 이미지 클릭 시 파란 배경)을 고르고 열차번호를 목록 선택 **또는 입력창에 직접 입력** → [추적시작]. **현재 운행 중이 아닌 열차번호도 추적 가능**. 추적 중 열차번호가 점유한 역 화면으로 자동 전환, **화면 상단 중앙에 추적 중 심볼** 표시. [추적종료].
- **역실적 조회 (p.57-59)**: 조건 날짜·표시시간·선별·위치(상/하행)·역리스트 → [검색] → 열차등급/열차번호/도착·정차·출발시각/도착·출발진로. [인쇄][닫기].
- **열차실적 조회 (p.59-61)**: 날짜·선별 → [열차번호검색] → 운행방향·열차번호 선택 → [검색]. 같은 열.
- **운휴열차 조회 (p.61-62)**: 노선·날짜 → 열차번호/역/운휴구간.
- **임시열차 조회 (p.62-63)**: 날짜·선 → 등급/열차번호/시발역/종착역/진입시각/방향/회차열번.
- **지연열차 조회 (p.63-64)**: 날짜·선별·열차등급·위치·지연기준(마지막 역만 / 경유역 중 하나라도)·지연시간 → 열차번호/역/지연시간/지연코드.
- **수동제어 이력 (p.77-83)**: 열차번호(날짜·역), 역모드(날짜·역), 현장설비(날짜·역·구분 선로전환기/신호기/진로), 장비계절체, 장비고장복구. 모두 [검색][인쇄][닫기].
- **온라인스케줄 이력 (p.83-85)**: 조작날짜·조작타입(ID생성/수정/삭제, 스케줄생성/수정/삭제)·콘솔정보·내용검색(각각 체크박스; 선택 안 하면 전부).
- **알람/이벤트 조회 (p.87-90)**: 경고종류 **중대한 오류(F)·오류(E)·경고(W)·안내(I)·디버깅(D)**; 검색조건 역명·항목수·경고종류·원인코드·현장설비·발생시간(체크박스로 활성화).
- **알람메시지 확인이력 (p.90-92)**: F·E 알람은 운영자 확인이 필요하며 누가·언제 확인했는지 조회. 조건: 날짜(확인일시/발생일시)·조작자·조작콘솔·종류.
- **노트관리 (시스템 관리 > 노트관리, p.92-96)**: 조회 조건 생성일자·노트종류(시설물/열차번호/이벤트/시스템)·대상명(예 SG_1A)·운영자ID; [새노트작성][노트추가기록][노트수정][노트삭제]. 새노트: 대상종류·대상명·제목·내용·리마인더·유효영역·자동 일지 생성.
- 그 밖(미구현): 콘솔정보관리·콘솔제어영역 패턴관리(p.65-70), 시스템상태 조회·LDTS 계절체·터미널서버(p.71-76), 오프라인 스케줄(p.99-).

- 파일: 열기(스케줄 열기), 인쇄. 편집: 열차복사 Ctrl+C(메모리에만 보관, 붙여넣기 때 생성) / 붙여넣기 Ctrl+V → 열차스케줄 추가 대화상자 / 열차생성 → 패턴선택(열차종별·방향·출발/마지막 역) → 추가 폼 / 열차정보수정 **F5 또는 Ctrl+R** / 노트편집.
- **열차정보수정 규칙 (p.139)**: 열차번호는 임시열차 투입·복사 신규를 제외하고 수정 불가, 운행방향·출발역·마지막 역 수정 불가. 열차종별·운행구분·운용 차종·속도종별·열차속성·분할합병·연계 열차번호·차량 수·운휴 여부 수정 가능. 도착·출발·정차시각·도착/출발진로 수정 가능, **이미 실적이 생긴 부분은 수정 불가**.
- 화면설정 > 화면모드설정: **툴팁보기**(열차 선택 → 열차번호·종류·시발종착·출발/도착시각·연계열번), **십자선보기**(왼쪽 클릭 → 그 지점의 시간·킬로정), **돋보기**(클릭 → 사각 박스에 확대 표시), **영역확대**(드래그). 열차검색(번호 입력 → 화면 이동).
- Dia 보기: 확대/축소(시간축 확대·축소, 역축 확대·축소; 키 `+` `-` `/`), 다이얼로그 ▸ 역축/시간축 설정(시작역·마지막역·시작시간·종착시간 → 적용), 열차정보보기옵션(스케줄선택·부대표시·요일별·열차방향·열차종류), 보이기/감추기, 열차별 색상 및 선속성(종류별 색·선 모양, 확인/초기값).
- 즐겨찾기: 설정(현재 시간축·역축 저장, 이후 처음 실행 때도 이 화면) / 가기. **F9**: 저장된 즐겨찾기에서 현재 시각·현재 역에 맞춰 이동.
- 노트편집: 노트정보관리 대화상자(생성일자·종류·대상역·운영자ID → 노트검색, 새노트작성: 종류·글자크기·표시기간·표시구간·리마인더·제목·내용, 노트수정, 표시된 노트 선택 후 F5).

## 열차자동제어 (실기3 3.4, p.58-62) → `simulator/autocontrol.js`
- 정의: AUTO = 스케줄(DIA)과 현장표시정보로 관제사 개입 없이 열차 진로를 자동 설정. 대상은 연동역의 도착·출발 주신호기(입환·분할·병합·경합 입환신호는 제외). 전제: 역제어모드 AUTO, 열차별·역별 운행정보 존재.
- 용어: 트리거 포인트(다음 역을 제어할 수 있는 궤도: 장내신호기 외방 2호주 또는 출발신호기 내방), 연동진로(복선: 장내 → 출발, 단조건은 출발 → 장내), 트러블등록(진로를 못 설정할 때 조건 해소 후 제어하려 등록), 대기행렬, 후방검색.
- 조건 ①~⑧: 진로 미사용, 궤도 무점유, 전환기 오방향 쇄정 없음, 신호기·전환기 고장 아님, TTB 없음, 역진로 없음, 단선 허가 해정. 복선: 정차 2분 이하는 통과(도착·출발진로 순차 요구), 초과는 장내진로만 요구. 요구 시점에 최종으로 역제어모드를 확인(AUTO 아니면 요구 안 함). AUTO 전환 시 홈의 열차 출발시각으로 우선순위를 정하고 방향별 진입 열차를 후방 트리거까지 추적.
- 구현한 것: 위 조건 중 ①~③(코어의 경합·점유·쇄정 검사 재사용), 모드 확인, 트러블등록·재요구, 통과/정차 분류, 우선순위(트리거가 빠른 열차 먼저), 홈 열차 처리. 근거 없는 상수(트리거 60초, 진입 20초, 출발 60초 전 요구)는 교육용 값입니다.
